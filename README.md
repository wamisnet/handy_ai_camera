# HandyCam 製品照合 (handy_ai_camera)

Android ハンディターミナルのカメラで **「今来るはずの製品と同じものか」** を画像で見極める検証アプリです。
OCR や深層学習の事前学習を必須とせず、**アプリ単体で「登録(学習) → 検査 → 手法評価 → しきい値調整」が完結**します。

対象としている 2 つのユースケース:

| ケース | 背景 | 見極めの鍵 | 難しさ |
|---|---|---|---|
| ウレタンフォーム 2 点セット | 黒 | 押印(凹凸)文字、外形、2 点の組み合わせ | 押印は陰影しか無く低コントラスト |
| グレー箱入り金属部品 | グレー | 穴の位置・数、外形 | 金属の映り込み、箱の縁 |

いずれも **手持ち撮影 = 距離・向き・傾き・照明が毎回変わる** ことを前提に、
「単純な画素一致は絶対に使わない」設計になっています(詳細は [docs/METHODS.md](docs/METHODS.md))。

## 何ができるか

- **製品登録**: 製品を作成 → 撮影するだけで、物体を切り出して正規化した「テンプレートビュー」を複数枚保存
  (フラッシュあり/なし両方、距離・角度違いを何枚でも追加可)
- **検査**: 製品を選ぶ → 撮影 → OK/NG。手法ごとの「本人スコア」「登録済み他製品の最良スコア」を並べて表示
- **ライブプレビュー**: セグメンテーション結果(輪郭・検出数)をリアルタイム重畳。構図・距離の確認に
- **複数手法を同時に評価・組み合わせ**: 形状 / 局所特徴(ORB・AKAZE・SIFT) / HOG / 整列後の勾配相関 / 押印エッジ Chamfer / 穴パターン / CNN 埋め込み(任意)
  を全部走らせ、重み・しきい値・必須(gate)を設定画面で自由に組み替え
- **ROI 指示**: 正規化画像上で「ここを重点的に見ろ」(押印文字など)をドラッグで指定、重みを付与
- **手法評価**: 登録ビューの Leave-One-Out で手法ごとの分離余裕と推奨しきい値を算出 → ワンタップで反映
- **ログ**: 全検査の手法別スコアを CSV で保存。共有して PC(`pctools/analyze_log.py`)で解析
- **エクスポート/インポート**: テンプレート一式を zip で端末間コピー・バックアップ

## ビルド

```
# Android SDK (platform 34 / build-tools 34) と JDK 17+ が必要
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew :app:assembleDebug
# → app/build/outputs/apk/debug/app-{arm64-v8a,armeabi-v7a,universal}-debug.apk (ハンディ端末は通常 arm64-v8a)
```

依存は Maven Central / Google Maven から取得します(OpenCV 4.10 公式 AAR、CameraX 1.3、TensorFlow Lite 2.16)。
NDK は不要です(OpenCV はプリビルド)。minSdk 26 / targetSdk 34。

## 使い方(最短)

1. 「+」で製品を作る(種類: ウレタン2点セット / 金属部品(グレー箱) / 単品)
2. 製品を開いて **「撮影して登録」** → 物体を置いて撮影。2 点セットは左から A→B の順に並べる(初回のみ順序を使用、以後は自動対応付け)
   - 距離・角度を変えて **3〜5 回**。フラッシュあり/なしは自動で両方保存される
3. (推奨)パーツの **ROI** ボタンで押印文字の領域を囲む(重み ×2〜3)
4. 別の製品も同様に登録(他製品が無いと「識別余裕」が評価できません)
5. メニュー **「手法評価」→「評価を実行」→「推奨しきい値を適用」**
6. 一覧の **「検査」** → 撮影 → OK/NG と手法別スコアを確認。結果画面の「正しい/誤り」で記録を残す
7. しばらく運用したら「検査ログを共有」→ `python pctools/analyze_log.py verify_log.csv` でしきい値を詰める

詳しい運用手順は [docs/OPERATION.md](docs/OPERATION.md)、内部構成は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## ディレクトリ

```
app/            Android アプリ (Kotlin, CameraX, OpenCV)
  imaging/      YUV変換・前処理・セグメンテーション・正規化
  match/        照合手法 (Matcher 実装群)
  verify/       検査エンジン・判定ロジック・テンプレート読込・CSV ログ
  eval/         Leave-One-Out 評価
  ui/           画面
pctools/        PC 側補助 (ログ解析・合成画像シミュレータ)
docs/           設計・手法比較・運用手順
```
