# 運用手順

## 撮影環境の基本

- **ウレタン**: マットな黒い布/板を背景に。製品との距離をなるべく離す(床に黒布、製品を台に乗せる等)。フラッシュ差分は「背景が遠い」ほど効く
- **金属部品**: 箱ごと撮る。**一番上の 1 箱全体が白い点線のガイド枠に入る**ように構える。箱が何段か積まれていても、隣に別の箱があっても、アプリが一番上の箱の内側矩形(橙の枠)を検出してその内側だけを解析する。箱が画面からはみ出すと検出できず「箱 未検出」になる
- 登録は 1 箱で行って問題ない(テンプレートは箱から抜き出した部品だけ)。運用時に積み重なっていても照合には影響しない
- 画面上部の **検出数が緑(期待数と一致)** になっていることを確認してから撮影
- 撮影中は 1 秒弱、端末を動かさない(フラッシュ OFF/ON の 2 段で撮る)

## 製品登録

1. 「+」→ 製品名、種類を選ぶ
2. 製品を開き、背景の種類を確認(ウレタン: 黒背景、金属: グレー箱)
3. 「撮影して登録」
   - 2 点セットは **A を左、B を右** に置く(初回のみ)。2 回目以降は自動で対応付けされるので位置は自由
   - **距離を 3 段階(近・中・遠)、角度を 2〜3 種類** 変えて撮る。1 回の撮影でフラッシュあり/なし 2 枚ずつ保存される
   - 裏返しでも同一とみなす製品は「鏡像も同一」にチェック
4. 製品画面のサムネイルで、正規化画像が **同じ向きに揃っている** ことを確認(長押しで削除可)
5. 「ROI」→ 押印文字/特徴部分をドラッグで囲む → 重み ×2〜3 → 保存

## 検査

1. 一覧の「検査」(または製品画面の「検査」)
2. 検出数が緑になる位置で「撮影」
3. 結果画面
   - 上部バナー OK/NG
   - パーツごとに 手法 | 本人 | 他製品 | 判定 の表。**「他製品」列が本人に近い手法は識別に効いていない**
   - NG 理由(どの手法がどの条件で落ちたか)
   - デバッグ画像: セグメンテーション(緑=期待数一致、赤=不一致)、正規化画像
4. 「この判定は正しい / 誤り」を押して記録(後で PC 解析に使う)

## 検出数が合わないとき

| 症状 | 対処 |
|---|---|
| 1 つの製品が 2 つに割れる | 設定「モルフォロジーカーネル」を大きく(7〜11)。フラッシュ差分しきい値を下げる |
| 背景のゴミが物体になる | 「最小物体面積」を上げる(0.02〜0.05)。背景を暗く/遠く |
| 2 点セットが 1 つにつながる | 製品どうしを離して置く。カーネルを小さく |
| グレー箱で「箱 未検出」 | 箱全体をガイド枠に収める。縁のコントラストが弱い箱なら設定で箱補正を OFF にし、箱の内側で画面を埋める |
| グレー箱で箱の縁が拾われる | 箱補正が ON か確認。それでも拾うなら「背景色距離しきい値」を上げる(45〜60) |
| 検出数が期待より多い(厳格モードで不採用) | 隣の部品・ゴミが写っている。ガイド枠を小さく(0.8)するか、最小物体面積を上げる |
| 金属の暗い面が背景になる | 距離しきい値を下げる(25〜35) |

## しきい値調整の流れ

1. 2 製品以上を登録後、メニュー「手法評価」→「評価を実行」
2. 表の「余裕」が正 → その手法は登録データ上で完全分離。負 → 重なりあり
3. 「推奨しきい値を適用」で設定に反映
4. 設定画面で重み・gate を調整(METHODS.md の推奨構成を参照)
5. 実検査の結果を蓄積し、「検査ログを共有」で CSV を PC へ → `python pctools/analyze_log.py verify_log.csv feedback.csv`
6. 誤受入(違う製品を OK)が 1 件でもあれば、その手法の「余裕」を上げる/gate にする。誤拒否が多ければしきい値を下げる/ビューを追加

## 新製品の追加

- 登録 → ROI → 「手法評価」を再実行(既存製品との余裕が縮んでいないか確認)→ 必要なら適用
- 似た製品が増えるほど Feature の重要度が上がる。余裕が小さい組み合わせは ROI を見直す

## 端末間のコピー

- メニュー「エクスポート(zip)」で共有 → 別端末で「インポート(zip)」。同じ製品 id は上書き
- 設定(しきい値等)は端末ごと。設定画面の値を合わせるか、同じ手順で「推奨しきい値を適用」

## CNN 埋め込み(任意)を使う

1. PC で MobileNetV3-Small(ImageNet, include_top=False, pooling=avg)を TFLite に変換
2. 端末の `Android/data/jp.hirameq.handycam/files/models/embedding.tflite`(adb push、または端末のファイル管理アプリ)に配置
3. 設定 → 「CNN埋め込み(TFLite)」を有効化。モデルが読めないときは結果画面に表示されない(unavailable)
